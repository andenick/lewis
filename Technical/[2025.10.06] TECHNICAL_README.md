## Source Code

### Analysis Modules

#### `src/analysis/trade_data_loader.py`

**Purpose**: Unified data loading interface for all trade and BoP data sources

**Key Classes**:
- `TradeDataLoader`: Main data loading class

**Key Methods**:
```python
load_robin_trade_data()       # Load FRED trade data from the source store
load_robin_alfred_data()       # Load ALFRED vintage data
load_bop_monthly_data()        # Load monthly BoP data
load_country_bop_data(country) # Load country-specific BoP
load_annual_pct_data(country)  # Load annual % of GDP data
load_gdp_data()                # Load World Bank GDP data
create_integrated_dataset()    # Create complete integrated dataset
get_data_summary()             # Get summary of all datasets
```

**Usage Example**:
```python
from Technical.src.analysis.trade_data_loader import TradeDataLoader

loader = TradeDataLoader()

# Load all data
datasets = loader.create_integrated_dataset()

# Access specific datasets
us_data = datasets['us_annual_pct']
source_data = datasets['robin_fred']

# Get summary
summary = loader.get_data_summary()
```

**Dependencies**: pandas, numpy, pathlib

---

#### `src/analysis/bop_analysis.py`

**Purpose**: Analytical functions for Balance of Payments analysis

**Key Classes**:
- `BalanceOfPaymentsAnalyzer`: Main analysis class

**Key Methods**:
```python
load_data()                          # Load all integrated datasets
analyze_current_account(country)     # Analyze CA trends
compare_trade_balances()             # Cross-country comparison
identify_historical_periods(country) # Define key historical events
calculate_trade_statistics(country)  # Period-specific statistics
analyze_trade_components()           # Component analysis
export_analysis_results()            # Export to Excel
```

**Usage Example**:
```python
from Technical.src.analysis.bop_analysis import BalanceOfPaymentsAnalyzer

analyzer = BalanceOfPaymentsAnalyzer()

# Analyze US current account
us_ca = analyzer.analyze_current_account('US')

# Compare countries
comparison = analyzer.compare_trade_balances(1990, 2020)

# Calculate period statistics
us_stats = analyzer.calculate_trade_statistics('US')

# Export results
analyzer.export_analysis_results('comprehensive_analysis')
```

**Dependencies**: pandas, numpy, matplotlib, trade_data_loader

## Data Management

### Raw Data (`data/raw/`)

**Purpose**: Original, unmodified data files

**Contents** (from Classfiles/Final Project):
- US Balance of Payments data (BEA)
- UK Balance of Payments data (ONS)
- Germany Balance of Payments data (Bundesbank)
- World Bank GDP data
- IMF methodology manuals (BPM5, BPM6)
- Historical Statistics of the United States

**Key Files**:
- `United States/Table 1.1. U.S. International Transactions.csv`
- `United Kingdom/chapter1.xlsx` (ONS BoP)
- `United Kingdom/pnbp.csv`
- `Germany/*.csv` (25 Bundesbank BoP series)
- `BoP_*.xlsx` (processed by N.A.)
- `BPM6.pdf`, `BPM5.pdf`, `FAQ_BPM5to6.pdf`

**IMPORTANT**: Never modify files in data/raw/. All processing should:
1. Read from data/raw/
2. Process in memory or save to data/processed/
3. Save final results to Output/Data/Results/

---

### Processed Data (`data/processed/`)

**Purpose**: Intermediate processing results (not final deliverables)

**Contents**:
- Temporary processing files
- Intermediate calculations
- Data validation results

**Note**: Final processed data goes to Output/Data/Results/, not here.

## Troubleshooting

### Common Issues

**Issue**: `FileNotFoundError` when running scripts
**Solution**: Check paths are correct. Use absolute paths or run from correct directory.

**Issue**: source data files missing
**Solution**: Verify data source sync. Check `Output/Data/data source/README.md` for sourcing instructions.

**Issue**: R visualization fails
**Solution**: Check R package installation. Verify data files exist in expected locations.

**Issue**: Pandas version errors
**Solution**: Update pandas `pip install --upgrade pandas`
